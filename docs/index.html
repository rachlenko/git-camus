Git commit messages, reconsidered

Commit to the absurd.

git-camus reads your staged diff and writes a philosophical reflection on it — inspired by Albert Camus — using Ollama, OpenAI, Claude, or the Claude CLI, entirely on your own terms.

Why git-camus

Built for privacy, tuned for meaning.

Local-first by default

Runs on Ollama out of the box — no data leaves your machine unless you choose a hosted provider.

Privacy first

Nothing is logged or sent to third parties beyond the LLM provider you explicitly select.

Fast & lightweight

A single Python CLI with minimal dependencies — install it and it's ready in seconds.

Four providers, one command

Switch between Ollama, OpenAI, Claude, or the local Claude CLI with a single flag.

Contextual

Reads your actual staged diff, so every reflection is grounded in the change you made.

Configurable

Pick your model, prompt, and provider per project via environment variables or a config file.

Quick start

From pip install to your first reflection.

1

Install

Requires Python 3.9+. Install the latest release from PyPI, or pin a version.

pip install git-camus
# or a specific version
pip install git-camus==0.5.0
2

Stage your changes and run it

git-camus reads what's staged and writes the message for you.

git add .
git-camus

# preview without committing
git-camus --show

# steer the reflection with context
git-camus -m "fixed auth token expiry"
3

Choose a provider

Ollama runs fully local by default. Switch providers with --provider / -p, or set GIT_CAMUS_PROVIDER.

Ollama · default

Local model via OLLAMA_HOST. No key required.

OpenAI

Set OPENAI_API_KEY, run with -p openai.

Claude

Set ANTHROPIC_API_KEY, run with -p claude.

Claude CLI

Uses your local claude login — no API key needed.

# Use OpenAI
export OPENAI_API_KEY="sk-..."
git-camus --provider openai

# Use the Claude CLI (no API key needed)
git-camus --provider claude-cli

Command-line options

FlagDescription
--show, -sPreview the generated message without committing
--message, -mProvide context to guide the philosophical reflection
--provider, -pollama (default), openai, claude, or claude-cli
